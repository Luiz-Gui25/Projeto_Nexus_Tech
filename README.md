# Projeto_Nexus_Tech

Projeto acadêmico de desenvolvimento web desenvolvido como parte da minha formação em Desenvolvimento de Sistemas.

## Objetivo
Criar um site para apresentar serviços de tecnologia, suporte técnico, manutenção de equipamentos e produtos.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Funcionalidades
- Apresentação dos serviços oferecidos
- Navegação entre as páginas do site
- Interface voltada à divulgação de soluções tecnológicas
